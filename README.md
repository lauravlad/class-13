# Class 13

Predicate logic practice for PHIL 270, about 1 hour 15 minutes: symbolization fine-tuned.

- Start here: definitions flashcards
- Part 1: Things that may not exist (seeking, believing in, dreaming of)
- Part 2: Choosing predicates (adjectives that split and ones that don't)
- Part 3: Quantifier order (build the formula, like and mixed quantifiers, truth in a small UD)
- Part 4: Moving a quantifier
- Part 5: Paraphrasing complex sentences (nested quantifiers, equivalent forms)
- Test your knowledge: 10 questions at the end, with a score and review

After each answer, every choice shows what it means in plain English.

Every student gets the same exercises in the same order, so the class can work through them together. Progress is saved on each device.

Students need the class code from their teacher to enter.
